Seed demo siap pakai

Setelah login (OTP 246810), data sample sudah berisi WH01/WH02, item ITEM001–003, karton CTN000001… Available (kecuali CTN000001–003 sudah Shipped). Password akun demo: password123.

1

Inbound — terima karton baru

Supplier kirim barang; sistem generate barcode/QR lalu stok Available.

  1. Buka Inbound → Buat Inbound.
  2. Pilih Supplier, Warehouse (mis. WH01), tanggal; isi baris Item, Qty, Location, Exp Date, Batch, Status QI/UU (+ UU Date jika UU).
  3. Atau Import Excel / paste JSON API di panel integrasi.
  4. Simpan Draft → Generate Barcode / QR.
  5. Cetak/lihat label (toggle Barcode / QR / Both) → Konfirmasi.
  6. Cek Inventory Summary: qty Available bertambah.
2

Outbound — kirim ke customer (scan)

Picking berbasis scan barcode/QR; status karton → Reserved → Shipped.

  1. Buka Outbound → Buat Outbound.
  2. Pilih Customer + Warehouse yang sama dengan stok (WH01 untuk CTN000004+).
  3. Buat Draft → di bagian scan, ketik CTN000004 + Enter, atau klik quick pick, atau buka kamera QR/BC.
  4. Ulangi scan beberapa karton → Lines terisi otomatis per item.
  5. Konfirmasi → karton menjadi Shipped; cek Inventory & Reports.
warning Scan gagal biasanya karena warehouse tidak cocok, atau barcode sudah Shipped/Reserved. Contoh: CTN000001–003 seed sudah Shipped.
3

Quality Inspection (QI)

Inbound QI → antrean QI → Pass/Fail + disposition → hanya UU boleh Outbound.

  1. Buat Inbound Inspection Type = QI, generate barcode, Simpan & Konfirmasi → karton status QI Pending.
  2. Buka Quality Inspection → Inspect karton (checklist + foto) → Pass/Quarantine/Block/Return/Scrap → Complete QI.
  3. Uji Outbound: hanya barcode UU diterima; QI Pending/Quarantine ditolak. Cek Warehouse Map & Barcode Tracking.
3b

Adjustment — tempat atau qty

Pindah lokasi atau koreksi qty — hanya karton UU untuk adjustment normal.

  1. Buka Adjustment → Tempat / Quantity.
  2. Scan/quick pick Available (UU) → konfirmasi di halaman yang sama.
4

Barcode / QR tracking & laporan

Telusuri jejak karton dan rekap transaksi.

  1. Barcode Tracking — cari CTN000004 untuk lihat status & dokumen terkait.
  2. Laporan: Transaction History, Inbound, Outbound, Inventory.
  3. Reset dataset: Demo Data → Reset, atau dari hub Pengaturan.

Ringkasan status karton

Status Artinya Dari transaksi

Reserved Sudah di-scan di draft outbound Outbound picking
